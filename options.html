Just your browser and your servers.

API keys stay in the extension’s local storage and are never sent to content pages. Linkarr only reads your libraries; it never adds, downloads, plays, or deletes media. A click opens the existing title’s detail page or the add screen in a new tab. Links work immediately without an API key; with a key, library checks quietly update links in the background.

Access is requested only for the server origins you configure. Custom icons are fetched once and cached locally. Use HTTPS when your instances are not on a trusted local network.
